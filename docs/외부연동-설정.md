# 외부 연동 키 등록 매뉴얼

관리자는 사이트의 `/admin/settings/api-keys/guide` 화면에서도 같은 내용을 볼 수 있다.

AI 직무·산업 분석 서비스(`/analysis`)는 고용24, 카카오 로그인, 네이버 클라우드 SENS(문자 인증) 세 가지 외부 서비스를 쓴다. 키는 환경변수(`.env.local`)가 아니라 **관리자 화면**에 입력하고, 입력한 값은 DB의 `system_settings`에 저장된다.

## 0. 공통: 입력 위치

1. `superadmin` 계정으로 `/admin/login`에 로그인한다. 일반 `admin` 계정은 화면을 볼 수는 있지만 저장하면 403이 난다.
2. `/admin/settings/api-keys` 화면 맨 아래 **"외부 연동"** 섹션으로 간다.
3. 항목마다 새 값을 입력하고 **저장**을 누른다. 저장하면 이전 값을 덮어쓴다.
   - 비밀값(인증키, Secret)은 저장된 뒤 가려서(마스킹) 표시된다. 원문은 다시 볼 수 없다.
   - 식별자(Redirect URI, Service ID, 발신번호)는 원문 그대로 표시된다.
4. 개발 DB와 운영 DB의 `system_settings`는 서로 다르다. **운영 서버에도 따로 입력해야 한다.**

| 화면 항목 | 설정 키 | 구분 |
|---|---|---|
| 고용24 인증키 | `work24_api_key` | 비밀값 |
| 카카오 REST API 키 | `kakao_rest_api_key` | 비밀값 |
| 카카오 Client Secret | `kakao_client_secret` | 비밀값 |
| 카카오 Redirect URI | `kakao_redirect_uri` | 식별자 |
| SENS Access Key | `sens_access_key` | 비밀값 |
| SENS Secret Key | `sens_secret_key` | 비밀값 |
| SENS Service ID | `sens_service_id` | 식별자 |
| SENS 발신번호 | `sens_sender` | 식별자 |

키를 입력하지 않아도 서비스는 동작한다. 해당 기능만 꺼진 상태가 된다(아래 각 절의 "미입력 시" 참고).

## 1. 고용24 (채용 데이터)

**발급 위치**: 고용24 Open API 신청 화면

1. 고용24에서 Open API 이용을 신청한다.
   - 서비스(채용정보, 직업정보 등)마다 키가 따로 발급된다. 반드시 **"채용정보(채용 목록)" 서비스 키**를 신청한다.
   - 이 서비스는 `callOpenApiSvcInfo210L01.do`를 호출한다.
2. 발급받은 인증키(authKey)를 **고용24 인증키**에 입력한다.

**동작 확인**: `/analysis`에서 직무 분석을 실행한다. 옵션은 "채용 시장 트렌드 반영"을 켜고 범위는 국내로 둔다. 결과에 **"고용24 반영"** 배지가 보이면 정상이다.

**미입력 시**: 리포트는 그대로 생성된다. 다만 "고용24 채용 데이터가 반영되지 않았습니다." 안내가 붙는다.

## 2. 카카오 로그인

**발급 위치**: [Kakao Developers](https://developers.kakao.com) → 내 애플리케이션

> 기존 **카카오 지도 API 키**(JavaScript 키, "카카오 지도 API 키" 칸)와는 다른 키다. 로그인에는 **REST API 키**를 쓴다. 같은 앱의 키를 써도 되고, 앱을 새로 만들어도 된다.

### 2.1 값 가져오기
| 화면 항목 | 콘솔 위치 |
|---|---|
| 카카오 REST API 키 | 앱 설정 → 앱 키 → **REST API 키** |
| 카카오 Client Secret | 카카오 로그인 → 보안 → **Client Secret 코드** 발급 후, 활성화 상태를 **사용함**으로 변경 |
| 카카오 Redirect URI | 아래 2.2에서 등록한 주소와 **한 글자도 다르지 않게** 입력 |

Client Secret은 필수다. 비어 있거나 활성화가 꺼져 있으면 로그인이 실패한다.

### 2.2 콘솔 설정
1. **카카오 로그인 활성화**를 ON으로 바꾼다.
2. **Redirect URI**를 등록한다.
   - 개발: `http://localhost:3000/api/analysis/auth/kakao/callback`
   - 운영: `https://<운영 도메인>/api/analysis/auth/kakao/callback`
3. **동의항목**: "카카오계정(이메일)"을 **선택 동의**로 설정한다. 그 밖의 항목(닉네임, 전화번호 등)은 쓰지 않으므로 켜지 않는다.
4. **플랫폼 → Web → 사이트 도메인**에 `http://localhost:3000`을 넣는다. 운영에서는 운영 도메인을 넣는다.

### 2.3 동작 확인
- `/analysis/login`에 **"카카오로 로그인"** 버튼이 보이면 키가 인식된 것이다. 키가 없으면 "준비 중입니다" 안내가 대신 나온다.
- 필수 동의 2개(개인정보 수집·이용, 만 14세 이상)에 체크하고 로그인한다. 로그인이 끝나 보관함 화면으로 돌아오면 정상이다.
- 실패하면 로그인 화면에 오류가 표시된다(`?error=kakao|state|cancelled`).
  - `kakao`: 키나 Redirect URI 설정을 다시 확인한다.
  - `state`: 브라우저 쿠키가 막혀 있는지 확인한다.

## 3. 네이버 클라우드 SENS (휴대폰 문자 인증)

**발급 위치**: [네이버 클라우드 플랫폼](https://www.ncloud.com) 포털과 콘솔

### 3.1 값 가져오기
| 화면 항목 | 위치 |
|---|---|
| SENS Access Key | 포털 → 마이페이지 → 계정 관리 → **인증키 관리** → API 인증키의 **Access Key ID** |
| SENS Secret Key | 같은 화면의 **Secret Key** |
| SENS Service ID | 콘솔 → **Simple & Easy Notification Service** → **Project** 생성 → 프로젝트의 **SMS 서비스 ID**(`ncp:sms:kr:...` 형태) |
| SENS 발신번호 | 같은 프로젝트의 **SMS → Calling Number**에 등록되고 **승인된** 번호. 하이픈 없이 숫자만 넣는다(예: `0212345678`) |

- **발신번호 승인**: 발신번호 사전등록제에 따라 서류 심사(통신서비스 이용증명원 등)를 거친다. 승인 전에는 문자가 발송되지 않는다.
- **서브 계정 키**: 서브 계정의 키를 쓰려면 그 계정에 SENS 권한이 있어야 한다. 메인 계정 키로 먼저 확인할 것을 권한다(미확인 사항, `docs/ISSUES.md` ANL-05).

### 3.2 실제 발송 켜기 (환경변수)
SENS 키를 입력해도 바로 실제 문자가 나가지 않는다. 발송 방식은 환경변수 `SMS_PROVIDER` 하나로 정한다.

| 값 | 동작 |
|---|---|
| `log` 또는 미설정 | 개발용. 문자를 보내지 않고 인증번호를 **서버 로그**(`[SMS:log]`)에 출력한다. |
| `sens` | SENS로 실제 발송한다. |

- 실제 발송을 시험하려면 `.env.local`에 `SMS_PROVIDER=sens`로 적고 서버를 다시 시작한다.
- **운영에서는 반드시 `sens`로 설정한다.** 운영에서 `log`이면 인증번호가 로그에 남지 않도록 발송 자체를 거부한다(503 "문자 발송이 설정되지 않았습니다").

### 3.3 동작 확인
- `/analysis/login`에서 필수 동의 2개에 체크한다. 본인 휴대폰 번호를 넣고 **인증번호 받기**를 누른 뒤, 받은 6자리를 입력한다.
- SMS는 **건당 과금**된다. 시험 발송은 한두 번이면 충분하다.
- 제한 규칙(정상 동작임)
  - 같은 번호로 다시 보내려면 60초를 기다려야 한다.
  - 같은 번호는 하루(한국 시간 자정 기준) 5회까지 보낼 수 있다.
  - 인증번호는 3분 동안 유효하고, 5회 틀리면 무효가 된다.
  - 실패 메시지는 일부러 하나로 통일했다.

## 4. 문제 해결

| 증상 | 확인할 것 |
|---|---|
| 저장 시 403 | `superadmin` 계정인지 확인한다. |
| 카카오 버튼이 안 보임 | `kakao_rest_api_key`가 저장됐는지 확인한다(마스킹 값이 보이면 저장된 것). |
| 카카오 로그인 후 `error=kakao` | REST API 키, Client Secret 활성화, Redirect URI 일치 여부, 카카오 로그인 활성화를 확인한다. |
| 인증번호가 오지 않음(개발) | `SMS_PROVIDER`가 `log`이면 정상이다. 서버 로그에서 `[SMS:log]`를 찾는다. |
| 인증번호 요청 시 503 | 운영인데 `SMS_PROVIDER`가 `sens`가 아니거나, SENS 값 4개 중 비어 있는 것이 있다. |
| 고용24 배지가 안 붙음 | 옵션 "채용 시장 트렌드 반영" ON, 범위 국내, 키가 채용정보 서비스용인지 확인한다. 서버 로그 `[고용24]` 경고도 본다. |

배포 체크리스트는 `배포.md` (k)~(o)에 있다.
